# 🛒 Список покупок

Веб-приложение в одном файле (`index.html`). Работает в браузере, данные хранятся
локально (localStorage). Никакой установки не требуется.

## Открыть локально

Двойной клик по `index.html` — откроется в браузере. Работает офлайн.

## Публикация онлайн (бесплатно)

Ниже — три варианта. Все дают постоянную ссылку вида `https://...`,
которую можно отправить кому угодно. После публикации заработает кнопка
**«📤 Поделиться»** (список кодируется в ссылку).

---

### Вариант A. Netlify Drop — самый быстрый (рекомендую)

1. Откройте в браузере: **https://app.netlify.com/drop**
2. Перетащите **папку `shopping-list`** (целиком, не файл!) в пунктирную область.
3. Через пару секунд получите ссылку вида `https://random-name-123abc.netlify.app`.
4. Готово. Можно переименовать сайт в настройках Netlify, чтобы ссылка была красивее.

Плюсы: 30 секунд, без регистрации на первый запуск, неограниченное обновление
(просто перетащить папку снова).

---

### Вариант B. GitHub Pages — постоянная ссылка навсегда

1. Зарегистрируйтесь / войдите на **https://github.com**.
2. Создайте новый репозиторий (кнопка **+** → **New repository**).
   Имя любое, например `shopping-list`. Поставьте **Public**.
3. Загрузите `index.html` в репозиторий (кнопка **uploading an existing file**).
4. Зайдите в **Settings** → **Pages** → в разделе **Source** выберите ветку
   `main` и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты ссылка появится сверху: `https://ваш-логин.github.io/shopping-list/`.

Плюсы: бесплатно навсегда, удобно обновлять через git.

---

### Вариант C. Vercel

1. Зарегистрируйтесь на **https://vercel.com** (можно через GitHub).
2. **Add New** → **Project** → импортируйте репозиторий из GitHub (см. вариант B)
   ИЛИ перетащите папку через Vercel CLI.
3. Нажмите **Deploy**. Ссылка будет вида `https://shopping-list-xxx.vercel.app`.

---

## Как обновить после изменений

- **Netlify Drop**: просто перетащите папку `shopping-list` заново.
- **GitHub Pages**: загрузите новый `index.html` в репозиторий (или `git push`).
- **Vercel**: переразверните проект.

## «Поделиться списком» (после публикации)

В приложении нажмите **📤 Поделиться** — в буфер обмена копируется ссылка,
содержащая весь ваш список. Отправьте её — получатель откроет и увидит ваш
список товаров (его можно загрузить одной кнопкой).

> ⚠️ Важно: каждый экземпляр приложения хранит свой список только в своём
> браузере. «Поделиться списком» передаёт **снимок** списка по ссылке, а не
> общее хранилище. Для синхронизации между устройствами в реальном времени
> нужен бэкенд (это отдельная задача).
